# Advanced Calculator

An interactive web-based calculator with advanced functionality and keyboard support.

![Calculator Preview](calculator-preview.png)

## Features

- Basic arithmetic operations (+, -, ×, ÷)
- Percentage calculations
- Parentheses for complex expressions
- Square root function
- Memory operations (M+, M-, MR, MC)
- Keyboard support
- Error handling
- Responsive design

## Usage

### Basic Operations
- Click number buttons or use keyboard to input numbers
- Use operators (+, -, ×, ÷) for calculations
- Press '=' or 'Enter' key to see results
- Press 'C' or 'c' key to clear the display

### Advanced Features

#### Memory Operations
- **M+**: Add current display value to memory
- **M-**: Subtract current display value from memory
- **MR**: Recall value stored in memory
- **MC**: Clear memory

#### Special Functions
- **√**: Calculate square root of current number
- **( )**: Use parentheses for complex expressions
- **%**: Convert number to percentage

### Keyboard Shortcuts
- **0-9**: Number input
- **+, -, *, /**: Operators
- **Enter**: Calculate result
- **Backspace**: Delete last character
- **c/C**: Clear display
- **( )**: Parentheses
- **.**: Decimal point

2. Open it in any modern web browser
3. Start calculating!
