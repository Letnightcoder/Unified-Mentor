# Global Temperature Anomalies Infographic

An interactive visualization showing temperature changes from 1880 to 2020.

![image](https://github.com/user-attachments/assets/c578c5f9-caf5-45c9-97fa-3fb2f5e2418a)


## How to View

1. Open [index.html](Infographics-Project/index.html) in a modern web browser
2. The visualization will load automatically

## Features

- Line chart showing global temperature anomalies over 140 years
- Interactive hover effects to see exact values
- Responsive design that works on both desktop and mobile
- Clear temperature trend visualization with custom tooltips

## Interactions

- Hover over any point on the line to see:
  - The specific year
  - The exact temperature anomaly value for that year
- The chart automatically resizes for different screen sizes
- The tooltip appears when hovering and disappears when moving away

## Technical Requirements

- A modern web browser with JavaScript enabled
- Internet connection (required for Chart.js library)

## Files

- `index.html` - Main HTML file
- `styles.css` - Styling for the visualization 
- `script.js` - Chart configuration and data
